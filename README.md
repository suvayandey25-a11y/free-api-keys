# 🔑 Free API Keys Hub

A comprehensive website showcasing **free API keys and services** for various AI models, NLP tools, vision APIs, and more.

## 📌 Features

✨ **Easy-to-Use Interface** - Browse free API keys with a clean, modern design
🔍 **Search & Filter** - Find APIs by name or category
📚 **Complete Documentation** - Direct links to official docs and signup pages
🎨 **Responsive Design** - Works on desktop, tablet, and mobile devices
⚡ **Fast & Lightweight** - No dependencies, pure vanilla JavaScript

## 📖 How to Use

1. Visit the website
2. Browse all available APIs or use filters (AI, NLP, Vision, Other)
3. Search for specific services
4. Click "Docs" to view documentation
5. Click "Sign Up" to get your free API key

## 🛠️ Installation

Clone this repository:
```bash
git clone https://github.com/suvayandey25-a11y/free-api-keys.git
cd free-api-keys
```

Open `index.html` in your browser or deploy to GitHub Pages:
1. Go to repository settings
2. Enable GitHub Pages with main branch
3. Your site will be live at `https://suvayandey25-a11y.github.io/free-api-keys/`

## 📝 Adding New APIs

Edit `data.js` and add a new entry:

```javascript
{
    id: 16,
    name: "Your API Name",
    category: "ai", // or "nlp", "vision", "other"
    description: "Short description of the API",
    features: ["Feature 1", "Feature 2", "Feature 3"],
    freeLimit: "Details about free tier",
    documentation: "https://docs.example.com",
    signup: "https://example.com/signup",
    logo: "🎯"
}
```

## 🌍 Deploy

### GitHub Pages (Free)
1. Push to your repository
2. Enable Pages in Settings → Pages
3. Select main branch as source
4. Your site is live!

### Vercel (Free)
1. Connect your GitHub repository
2. Deploy automatically with each push

### Netlify (Free)
1. Drag and drop the folder to deploy
2. Or connect your GitHub repo
